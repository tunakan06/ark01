# NIGHTFALL — Tactical Defense

スマートフォンとPCのブラウザで遊べる、オリジナルのタワーディフェンスゲーム。

## 起動

Node.js 18 以上を使用します。

```sh
npm ci --cache /tmp/ark01-npm-cache
npm run dev
```

本番向けビルドは `npm run build`、確認用サーバーは `npm run preview`。

## 遊び方

- オペレーターカードを選び、道路以外のマスをタップして配置。
- コストは作戦中に自動回復。ユニットは射程内の敵を自動攻撃。
- 配置済みユニットのゲージが満タンになったらタップしてスキル発動。
- 長押しまたは右クリックで撤退。配置コストの半分を返却。
- 全5ウェーブを防衛すると勝利。敵が青い拠点に到達するとライフが減少。
- 右下のボタンで作戦開始、停止、倍速、リセット。

キャラクター・描画・名称はオリジナルです。ネイティブアプリ化やオンライン機能は含みません。
